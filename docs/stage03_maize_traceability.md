## Cross-cutting implementation

| Requirement | Code | Verification |
|---|---|---|
| Preserve original 48-source / 16-layer core, AOI, source contracts and exports | `maize_workflow.py`, `maize_extension.py`; unchanged `pipeline.py` | Original regression suite; immutable-byte and package tests |
| Exact 254 TIFF + 254 JSON inventory; no guessed future SXX; source-list audit | `tools/build_maize_manifest.py`, `maize_sources.json` | Exact count, dimensions, gap resolution and guide SHA tests |
| Source JSON identity, range-only reads, native grids, masks, valid zero, checksums | `maize_sources.py` | Mocked HTTP plus real raster round-trip tests; representative official bounded reads |
| Fractional native areas, common valid support, ties, water, five unique models, all ten pairs | `maize_analysis.py` | Hand-checkable synthetic science tests, shifted-grid intersections and missing-model rejection |
| Matched historical/future, cross-SSP/period and ENSEMBLE diagnostics | `maize_analysis.py`, `maize_extension.py` | Matched-dimension, common-support and zero-denominator tests |
| Shared scales, source legends, raw-value extrema, exact derived geometry | `maize_render.py`, `source_metadata/` | Native export and legend tests; original legend bytes unchanged |
| One-cell Colab, completed-package reuse, offline filters and both comparison legends | Notebook bundle, `maize_workflow.py`, `assets/maize.js` | Isolated notebook startup, end-to-end package and offline browser tests |
| Full evidence and non-overwriting packages | `maize_extension.py` | Per-file hashes, original exports retained, no stale or missing downloads |

The implementation accepts source grids with unequal alignment only through exact geometric overlay; a derived analytical raster is not created for a nonaligned partition. Exact GeoJSON is retained instead. Optional all-three-SSP/all-four-period union analyses are not substituted for the required matched pairwise comparisons. The full original guideline remains available for audit.
