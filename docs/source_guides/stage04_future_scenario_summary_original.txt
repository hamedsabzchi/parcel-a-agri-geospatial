STAGE 04 IMPLEMENTATION GUIDE
Decision-Oriented Future Scenario Summary
================================================================================

DOCUMENT PURPOSE
----------------
This document instructs a coding agent to implement Stage 04 by adding one carefully integrated tab to the accepted Stage 03 Parcel A dashboard. Stage 04 is an additive decision-support synthesis layer. It does not replace Stage 03 source data, analytical outputs, maps, tables, methods, verification evidence, or dashboard functionality.

Stage 04 must allow non-specialist decision-makers to compare verified future crop suitability, attainable yield, model agreement, and inter-model spread without manually reviewing hundreds of individual scenario maps. The tab must remain evidence-oriented and neutral. It must not generate crop recommendations, investment decisions, rankings, field-level forecasts, or unsupported conclusions.

TASK
----
Implement Stage 04: Decision-Oriented Future Scenario Summary.

INPUT
-----
Use the original accepted Stage 03 ZIP package as the only input package.

Do not use a previously modified Stage 04 ZIP as input.
Do not use an extracted directory whose provenance cannot be tied to the original Stage 03 ZIP.
Do not silently supplement the package with external, synthetic, manually typed, or previously cached analytical values.

The Stage 03 ZIP is expected to contain, at minimum:
- dashboard/parcel_a_data_inventory.html
- dashboard/assets/
- tables/
- clipped_data/
- metadata/
- Stage 03 logs, manifests, QA records, provenance records, and verification records

If a required source is absent, record the gap and disable the affected Stage 04 element. Do not fabricate values or show a misleading empty chart.

REQUIRED YIELD CALCULATIONS
---------------------------
Use fractional source-cell intersection areas in hectares and the existing Stage 03 area method.

For model m and analytical unit i:
- y_mi = valid modelled yield value;
- a_i = AOI intersection area;
- V = exact common valid set across the five included models;
- P = units in V satisfying the defined positive-yield criterion;
- Z = units in V satisfying the defined valid-zero criterion.

Per-unit five-model mean:
mean_i = sum(y_mi for the five included models) / 5

Per-unit five-model median:
median_i = median(y_mi for the five included models)

Whole-AOI mean, valid zeros retained:
sum(mean_i × a_i for i in V) /
sum(a_i for i in V)

Positive-yield area:
sum(a_i for i in P)

Positive-yield percentage:
100 × positive_yield_area /
common_valid_area

Mean within positive-yield area:
sum(mean_i × a_i for i in P) /
positive_yield_area

Valid zero-yield area:
sum(a_i for i in Z)

Valid zero-yield percentage:
100 × valid_zero_yield_area /
common_valid_area

Important positivity rule:
The source package must define whether a positive-yield unit means:
A. the selected five-model summary diagnostic is greater than zero; or
B. all five model values are greater than zero; or
C. another explicitly verified rule.

Use the Stage 03-defined rule if available. If Stage 03 does not define it, use option A for the selected five-model mean diagnostic, label the rule explicitly, and record it in Stage 04 methodology. Do not silently mix definitions across cards, maps, trends, and tables.

If positive-yield area equals zero, report:
Not applicable: no positive-yield area.

VALID-ZERO CLASSIFICATION RULE
------------------------------
For whole-AOI summaries, every valid model zero remains included.

For the five-model summary map, define a valid zero-yield analytical unit as a unit where the selected summary diagnostic equals zero. Record the number of zero values among the five models separately if the Stage 03 package supports it.

Do not call a unit zero yield when it is masked in one or more models and therefore excluded from exact five-model common support.

MODEL CV RULE
-------------
For each common-support analytical unit with five valid model values:
- calculate the population standard deviation across the five model values;
- calculate CV = population standard deviation / five-model mean only when the five-model mean is greater than zero;
- set CV to not applicable where the mean is zero;
- never replace undefined CV with zero.

For the selected-scenario summary card, use the area-weighted mean of valid per-unit CV values unless Stage 03 already defines another verified aggregate. Declare the aggregation method.

Display CV as either:
- ratio, with at least two decimal places; or
- percentage, explicitly multiplied by 100 and labelled with %.

Do not display a ratio such as 0.07 as 0 because of integer rounding.

Required tooltip:
CV describes spread among the five climate-model values relative to their mean. It does not measure all sources of uncertainty.
