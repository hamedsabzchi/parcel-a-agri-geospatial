Data and Methods
Statistics use physical areas where the original raster cells intersect Parcel A. Missing pixels, native resolution, time coverage and source limitations remain visible.
Time series first aggregate valid native intervals in each cell, then apply completeness thresholds and calculate the AOI summary. Missing observations are not replaced by zero. The default 90% thresholds are project choices; retained incomplete totals remain labelled partial.
GAEZ attainable yield describes the best occurring suitability class in a source cell. Irrigation values describe a share of cropland in a source cell. Neither is converted to parcel production or irrigated hectares.
